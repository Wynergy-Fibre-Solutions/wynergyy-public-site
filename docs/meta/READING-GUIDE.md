\# Reading Guide



This guide explains how to read this repository without technical background.



You do not need to read everything.

You only need to know where to start.



---



\## Step 1: Start Here



Begin with:



\- `docs/START-HERE.md`



This document explains the purpose of the repository, what it represents, and how the pieces fit together.



---



\## Step 2: Understand the Boundaries



If you want to understand limits, controls, and intent, read:



\- `docs/governance/EXTERNAL-REVIEW-BOUNDARIES.md`

\- `docs/governance/LIMITS-OF-AUTOMATION.md`



These documents explain what this system \*\*does not do\*\*, which is as important as what it does.



---



\## Step 3: Inspection and Evidence



For audit, inspection, or verification purposes, read:



\- `docs/governance/INSPECTION-WALKTHROUGH.md`

\- `docs/governance/EVIDENCE-HANDOVER-PROTOCOL.md`



These define how the system can be reviewed without internal access.



---



\## Step 4: Structure and Context



To understand how the repository is organised, read:



\- `docs/meta/REPO-STRUCTURE.md`



This explains why files are arranged as they are.



---



\## Important Notes



\- This repository is designed for \*\*external visibility\*\*.

\- There is no hidden logic.

\- There are no runtime artefacts.

\- Documentation is the primary interface.



You are not expected to read everything in one sitting.



---



End of guide.

Operating Principles

Evidence First

All progress is documented. No system change is considered complete unless it is evidenced in writing.

Public Scope Boundary

This repository contains public-facing declarations and schemas only.

  • Included: ACE schemas, validation logic, principles, status
  • Excluded: WyneOS engines, PAMI logic, orchestration layers
  • Excluded: Cryptography, autonomy, runtime execution

Intentional Disclosure

Nothing operational is exposed. Interfaces may be visible. Execution is not.

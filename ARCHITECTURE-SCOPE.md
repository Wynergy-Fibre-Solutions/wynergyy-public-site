\# Architecture Scope



This repository represents a public contract layer.



It reflects:

\- Intent

\- Governance

\- Structure

\- Boundaries



It does not contain:

\- Execution engines

\- Runtime services

\- Predictive logic

\- Decision-making systems



Those systems exist separately and are not disclosed here.



This separation is intentional and enforced.
